## 💡 コンセプトと開発思想：確率論的AIジャッジから「決定論的ストライクゾーン」へ

市販の英語発音アプリの多くは、ディープラーニングによる統計モデルを用いて「78点」「Good!」といったブラックボックスなスコアを返す設計になっています。しかし、運動学習（Motor Learning）の観点から見ると、これらは「結果の通知（Knowledge of Results）」に過ぎず、**「口腔内のどこがどう物理的にズレており、舌や唇をどう動かせば良いのか」という身体操作（Knowledge of Performance）の処方箋**が得られません。

NinjaPhonetics が目指したのは、**野球の「ストライクゾーン」**です。

ピッチャーが投球練習をするとき、「今の球は62点」と言われるよりも、「外角高めに3インチ外れた」とボールの通過ゾーンが見えるからこそ、次の1球で指先のリリースや体重移動を微調整できます。

発音も全く同じです。
声道の幾何学的形状と音響物理は1対1で直結しています。  
「舌の側面を上顎の奥歯に密着させ、舌根を引く」という調音操作を行えば、物理法則に従って **$F_3$ が急降下し、$F_2$ との差分 $\Delta(F_3 - F_2)$ が $1000\,\text{Hz}$ 未満のストライクゾーンに必ず吸い込まれます**。

母国語特有の干渉パターンごとに「最も効く物理指標」を選び抜き、直感的なバイオフィードバック計器として提供することで、誰でも迷わず最短でネイティブの調音ターゲットに到達できるようにします。

## 🛠️ 主な機能とUI設計（Biofeedback Scope）

1. **3段連動オシロスコープ（プロフェッショナル・ダーク計器）**
   * **第1段（Waveform）**: 生波形（振幅エンベロープ）。無音区間、子音破裂パルス、音節の長さを視認。末尾（`-ly` や `-y` 等）の減衰を削らない適応型時間マージン設計。
   * **第2段（$F_2 \text{ and } F_3$ ホルマント）**: 青（$F_3$）と緑（$F_2$）の軌跡。周波数上限を $4000\,\text{Hz}$ まで拡張し、高域の共鳴抜けを完全にカバー。
   * **第3段（$\Delta(F_3 - F_2)$ 差分 & Rストライクゾーン）**: $0\sim 1000\,\text{Hz}$ の帯域全体を **半透明の赤色シェードパッチ（R STRIKE ZONE）** として可視化。黄色いトレースがこのゾーンに潜り込んでいるかを一目で直感判別。
2. **広帯域スペクトログラム背景**
   * 音声の時間–周波数解析が表示されます。
   * LPC（Burg法）によるトラッキング誤認や線の乱れが生じた際も、物理的な共鳴エネルギー帯（白い光帯）で真のホルマントを確認可能。
   * ツールバーの `Spectrogram: ON/OFF` ボタンで瞬時に表示切替が可能。
3. **高機能オーディオ & 計測操作**
   * **ピッチ維持タイムストレッチ再生**: HTML5 `preservesPitch` 機構を採用し、0.7x や 0.5x のスロー再生時でも音程（ピッチ・ホルマント）を変えずに肉声を再生。
   * **お手本自動再生**: お手本プリセット選択から1秒後に自動で再生がスタート。
   * **ドラッグ選択 & 縦カーソル連動**: 注目したい子音・母音区間をドラッグ選択して反復試聴。可動赤色カーソルで任意の位置のミリ秒単位の物理周波数（$F_3, F_2, \Delta$）をリードアウト表示。
   * **ワンクリック・エクスポート**: 表示中の解析プロットを画像（`PNG`）として、音声を非圧縮WAV（`WAV`）として即座にダウンロード可能。

## A1: 接近音・液音の動態

日本人学習者が特に手こずる重要単語にフォーカスし、高精度な音響解析（Burg法 LPC + 広帯域スペクトログラム）で人口音声のお手本と自分の声をミリ秒単位で比較できます。

### 重点対象語と音響チェックポイント（全10プリセット）

| お手本単語      | 音響物理ターゲット                                           | 指導・調音のチェックポイント                                 |
| :-------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **Right (US)**  | **$F_3$ の垂直落下**<br>$\Delta(F_3 - F_2) < 500\,\text{Hz}$ | 語頭で青（$F_3$）と緑（$F_2$）が抱き合うように接近し、差分ライン（黄色）が $1000\,\text{Hz}$ のストライクゾーン深くに潜り込む（舌先を巻くのではなく、**舌の側面を上顎の奥歯に密着させるアンカー**）。 |

## B1: 歯擦音スペクトル重心スコープ (/si/ vs /ʃi/)

日本人学習者が「see」を「she」と混同してしまう原因（日本語のサ行「シ」[ɕ] による歯茎硬口蓋化トラップ）を、**$1,000\sim 10,000\,\text{Hz}$ 広帯域スペクトログラム**と**スペクトル重心（Spectral Center of Gravity: COG）**によってミリ秒単位で可視化する2段階診断モジュールです。

### 物理ターゲットとストライクゾーン

* **`/s/` STRIKE ZONE（緑色帯：$\text{COG} \ge 5,500\,\text{Hz}$）**: 舌先を下前歯の裏に固定し、口角を横に引いて前歯の狭い隙間へ気流を集中させることで、高周波の鋭い乱流エネルギーが $5,500\sim 8,000\,\text{Hz}$ に集中します。
* **`/ʃ/` & 日本語「シ」`[ɕ]` ZONE（青色帯：$\text{COG}\ 2,300\sim 4,600\,\text{Hz}$）**: 舌端を後部歯茎へ引き唇を丸める英語の `/ʃ/`、および舌の中央（舌背）が硬口蓋へ盛り上がる日本語の `[ɕ]`（シー・シート等）は、いずれも共鳴重心が $2,300\sim 4,600\,\text{Hz}$ 帯に落ち込みます。Target が `/s/` にもかかわらずこの帯域に入った場合は **「シ `[ɕ]` TRAP」** として即時警告を出します。

### 2つのトレーニング・サブタブ構成

#### 1. 単語キャリブレーション（単音・ミニマルペア + カタカナ比較・全13プリセット）
語頭の無声歯擦音区間を MMS-FA で自動切り出し、個別の舌位置・気流の集中度をキャリブレーションします。

| カテゴリ                  | お手本プリセット                                             | 音響物理ターゲット・チェックポイント                         |
| :------------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **鋭利歯擦音 `/s/` 基準** | **See (US / UK)**<br>**Seat (US)** / **Sip (US)**<br>**City (US)** | 後続の狭母音 `/iː/` や `/ɪ/` に引きずられて舌背が盛り上がらないよう維持し、子音区間全体で **$\text{COG} \ge 5,500\,\text{Hz}$**（緑色ゾーン）をキープ。特に *City* が *shitty* に聞こえる事故を防止。 |
| **後部歯茎音 `/ʃ/` 基準** | **She (US / UK)**<br>**Sheet (US)** / **Ship (US)**          | 舌先を引き前口腔共鳴腔を広げることで、**$\text{COG}\ 2,300\sim 4,600\,\text{Hz}$**（青色ゾーン）へ安定着地。*See / She*、*Seat / Sheet*、*Sip / Ship* で $2,000\,\text{Hz}$ 以上の落差を確認。 |
| **日本語カタカナ比較**    | **シー / シート / シップ / シティ (JP)**                     | 日本語の `[ɕ]` が $3,500\sim 4,400\,\text{Hz}$ 帯に落ち込む干渉パターンと、語尾母音付加（`-to`, `-pu`）を可視化比較。 |

#### 2. 早口言葉チャレンジ（調音切り替えストレステスト）
* **課題文**: *"She sells seashells by the seashore. The shells that she sells are seashells, I'm sure."*
* **鋸歯状（ノコギリ波）COG 軌跡の検証**: 文中で `/ʃ/`（*she, shells, -shore, sure*）と `/s/`（*sells, sea-*）が高速交代する際、ネイティブの発話では COG ラインが **$3.5\,\text{kHz}$ 前後と $6.5\,\text{kHz}$ 前後の間をノコギリ波のように上下往復**します。
* **分離落差（$\Delta\text{COG}$）と全12トークン別スコアカード**: パッセージ全体の平均 `/s/` COG と平均 `/ʃ/` COG の落差 **$\Delta\text{COG} = \overline{\text{COG}}_{/s/} - \overline{\text{COG}}_{/\ʃ/} \ge 1,600\,\text{Hz}$** を合格基準とし、12箇所すべての歯擦音トークンについて個別実測値と合否バッジを表示します。

## E2: プロソディ＆ストレス拍診断

「単語ひとつひとつは通じるのに、文になると平坦で聞き返される（モーラ拍干渉）」を解消するため、**発話速度やポーズ（息継ぎ）の長さに左右されない4つの音響リズム指標**と **MMS-FA（Wav2Vec2 強制アライメント）** による音素単位の自動計測を組み合わせた総合リズム診断エンジンです。

### 課題とベンチマーク

* **標準パッセージ（P1: 北風と太陽 / *The North Wind and the Sun* 全文113語）**: US-Native・UK-Native・JP-Accented 話者コーパスから算出した **95%信頼楕円（Mahalanobis距離 $D_M^2 \le 9.21$）** をネイティブ・ストライクゾーンとして描画。
* **自由文ダイナミック判定モード**: テキストエリアを任意の英文に書き換えた場合も、内蔵の G2P（音素変換）と機能語辞書により即座に強勢母音・弱母音を自動分類し、動的に合否判定を実行します。

### 4つの決定論的リズム物理指標

| 指標名                                            | 定義・物理的意味                                             | ストライクゾーン基準                                       |
| :------------------------------------------------ | :----------------------------------------------------------- | :--------------------------------------------------------- |
| **$V_{\text{diag}}$（弱化必須語 中央値）**        | 冠詞を除く主要な機能語（*to, for, of, in, was, were, that, and, his* 等）の母音持続時間の中央値。 | **$\le 45\,\text{ms}$**<br>（一瞬で脱力通過できているか）  |
| **$\text{Schwa P75}$（弱母音 75パーセンタイル）** | 文中の無強勢母音（`stress=0`）全体の第3四分位持続時間。      | **$\le 65\,\text{ms}$**<br>（弱音節が間延びしていないか）  |
| **$R_{\text{CF}}$（内容語 / 機能語 母音長比）**   | 内容語（名詞・動詞・形容詞等）の平均母音長 $\div$ 機能語の平均母音長。ポーズ時間に依存しない純粋な強弱コントラスト比。 | **$\ge 1.30\text{x}$**<br>（強弱のメリハリがついているか） |
| **$\text{nPVI-V}$（正規化母音対変動指数）**       | 隣接する母音同士の持続時間差の正規化平均。モーラ拍（等時拍）では低く、ストレス拍では高くなる。 | **$40 \sim 60$**<br>（英語特有の伸縮リズムか）             |

### 3種類の多次元ビジュアライゼーションと復習ツール

1. **2D 総合楕円プロット（$R_{\text{CF}} \times \text{Schwa P75}$）**: ネイティブ母集団の 2D 信頼楕円上に自分の試行軌跡（Trial #1, #2...）を重ねてプロットし、練習ごとの移動ベクトルを追跡。
2. **指標 1D 分布（KDE バイオリンプロット）**: US / UK ネイティブと日本語話者の分布曲線上で、4指標それぞれの現在位置を一目で確認。
3. **機能語 Swarm プロット & クリック再生発話マップ**: 単語別の母音長分布比較に加え、解析結果の英文マップ上の**任意の単語をクリックするとその単語区間だけを即座にピンポイント再生**でき、引き伸ばしてしまった機能語（赤・黄ハイライト）を耳と目で修正できます。
